🎛️ Music Editorial Console

Publishing control panel template. It prepares structured release metadata; production publishing should be protected by authenticated server-side admin access before public deployment.

Release metadata

Editorial workflow
  1. Receive artist/label submission.
  2. Verify identity and rights.
  3. Review metadata, artwork, audio and lyrics.
  4. Approve, request correction or reject.
  5. Publish the release and connect artist/album/video pages.
  6. Monitor corrections, takedowns and rights requests.
