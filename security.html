Security

Security is treated as an important part of the C. O. Eric software projects.

Report a vulnerability

For security issues affecting Universal Browser or Universal Reader, please report the issue through the relevant official GitHub repository and clearly mark it as a security concern. Avoid posting secrets, personal data or exploit details that could unnecessarily enable abuse.

What to include

  • Affected project and version or commit, if known.
  • Device/Android version and clear reproduction steps.
  • Security impact and any relevant logs with sensitive information removed.

Project status

Security practices and reporting channels may evolve as the projects move toward production distribution.
