Mobile-friendly download guide

How to download on Android

Choose the smallest resolution that looks good enough on your screen. Lower resolution usually means less data, but actual file size depends on video length and compression.

  1. Tap a resolution. Try 240p first on a limited data plan; use 360p or 480p if you want a clearer picture.
  2. If the video plays instead of downloading, open the browser menu (⋮) and choose Download if available. Some websites ignore the download attribute on links to another domain.
  3. Check the download notification. Wait for the file to finish before leaving the page or switching networks.
  4. Play the saved file. WebM may not play in every built-in gallery app; try a video player that supports WebM if necessary.
  5. If a link fails, use its “licence & credits” or source-page link to look for a current file. A direct link can stop working if the source changes its files.

Download links point to third-party hosts. This page does not proxy or store these films, and it cannot guarantee that every external host is online or that every browser will force a download.

How downloads work: This page reads its titles and download links from the local anime-downloads.json file in this website repository. Download buttons appear only for files listed there. Most video files are currently hosted by their original external sources; they are not copied into this website repository. Commercial Anime/Donghua are listed as downloadable only when distribution permission is available.

English subtitles & branding: the player supports English subtitle tracks when a source supplies them, and the C. O. Eric watermark appears in our player. A player overlay cannot permanently watermark a third-party file; permanent branding of a downloaded file requires media we control and process. Use only streams and downloads you are authorized to access or save.
