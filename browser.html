Universal Browser · Android

The web, without limits.

A full-featured GeckoView-based browser designed to combine powerful browsing tools, privacy controls, downloads, tabs and an ambitious extension ecosystem in one focused app.

View on GitHubContact the project
⚡

Powerful browsing

Desktop-site controls, page zoom, find in page, tabs, private browsing, bookmarks, history and site controls are part of the browser experience.

🧩

Extension ecosystem

The project is designed around GeckoView while working toward practical support for extensions from major browser ecosystems. Compatibility is validated rather than assumed.

⬇️

Serious downloads

Download management is designed for ordinary files and supported media, including direct media resources and HLS streams where technically possible.

Built for real devices

Universal Browser is being developed as a native Android browser rather than packaging the Chromium engine. The goal is a capable browser that remains practical on modest Android hardware.

Privacy & control

Private browsing

Open private tabs when you don't want a normal browsing session.

Site controls

Keep permissions and browser behavior visible and manageable.

No fake promises

Extension compatibility and media capabilities are treated as engineering features to test, not marketing claims that every site or extension will work.

Development status

The browser is under active development. Check the GitHub repository for source code, releases, issues and the latest project status.
