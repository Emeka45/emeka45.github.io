Universal Browser · Android

The web, without limits.

A full-featured GeckoView-based browser designed to combine powerful browsing tools, privacy controls, downloads, tabs and an ambitious extension ecosystem in one focused app.

DownloadsView on GitHub

⚡ Powerful browsing

Desktop-site controls, page zoom, find in page, tabs, private browsing, bookmarks, history and site controls.

🧩 Extension ecosystem

GeckoView-first extension architecture with practical compatibility work across major browser ecosystems.

⬇️ Serious downloads

Download management for ordinary files and supported media, including direct resources and HLS where technically possible.

Built for real devices

Universal Browser is a native Android browser rather than a Chromium package. The goal is a capable browser that remains practical on modest hardware.

Privacy & control

Private browsing

Open private tabs for sessions you don't want treated as normal browsing history.

Site controls

Keep permissions and browser behavior visible and manageable.

Transparent compatibility

Extension and media compatibility is validated rather than presented as a promise that everything works.
