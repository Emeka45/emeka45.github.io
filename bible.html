🔒 Check each text’s licence

Translations can have different terms. Before reuse or commercial redistribution, check the selected text’s licence and source; this Hub links to source information rather than assuming every version is reusable.

Bible versions are organised so popular English editions come first. Open “Change Bible version / language” only when you want the full catalogue. NIV is linked to its licensed reading page because it is not available in the current open-text catalogue.
This Hub uses the Free Use Bible API for a large catalogue. API access may be free, but that does not automatically make every translation free to republish or redistribute. Check the selected translation’s source and licence before reuse, especially for commercial purposes. Copyrighted editions such as NIV are linked to their licensed reading provider instead of being copied here.
