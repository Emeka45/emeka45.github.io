How every topic will be built

We will use one consistent content model so the library becomes deeper than a collection of copied lesson notes.

Topic → explanation → key terms → worked examples → real-world application → common mistakes → practice questions → answers/explanations → related topics → exam relevance → further reading.

Where a topic belongs to a Nigerian curriculum, the class/subject mapping can be shown alongside it. The current NERDC curriculum remains the authoritative reference for curriculum structure; our explanations are original educational content.

Priority content build

Phase 1 focuses on high-demand Nigerian learning areas before expanding into the long tail.

1. Core school knowledge

Mathematics, English, Basic Science, Biology, Chemistry, Physics, Civic Education, Government, Economics and Computer/IT.

2. Exam preparation

Topic-by-topic revision and original practice for JAMB/UTME, WAEC, NECO, BECE and NABTEB.

3. University knowledge

Course notes, academic writing, research methods and professional subjects, expanding from the existing university section.
