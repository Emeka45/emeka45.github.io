About the work

The goal behind these projects is straightforward: build software that solves everyday problems without making users fight the interface. That means treating performance, privacy, accessibility and reliability as product features rather than afterthoughts.

Universal Browser explores what a capable mobile browser can look like when it is built around GeckoView. Its development focuses on useful browser controls, downloads, media handling, private browsing and an extension architecture that is transparent about compatibility instead of promising that every extension will work.

Universal Reader takes a similar approach to documents and ebooks. The project is intended to keep reading focused, practical and comfortable while its capabilities mature.

This website is the public home for those projects. It provides project information, release information, downloads when they are published, security and privacy information, and links to the source repositories where development can be followed.
